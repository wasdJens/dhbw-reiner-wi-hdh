Toolbox

Bauteile moderner Webseiten: was sie tun, warum sie so gebaut werden und worauf es bei der Barrierefreiheit ankommt. Jede Seite der Toolbox ist mit den Patterns gebaut, die sie beschreibt.

Stand
26 von 26 Patterns dokumentiert

Struktur

  • HTML-Grundgerüst

    Das Minimum jeder Seite: Dokumenttyp, Sprache, Zeichensatz, Viewport.

  • Landmarks

    Header, Navigation, Hauptinhalt und Footer – Bereiche, zu denen Screenreader springen können.

  • Überschriften-Hierarchie

    Überschriften nach Bedeutung, nicht nach Größe: eine lückenlose Gliederung der Seite.

Text

  • Listen

    Drei Arten von Listen für drei Arten von Inhalt.

  • Links

    Relativer Pfad, absolute URL oder Anchor – und ein Linktext, der das Ziel nennt.

  • Tabellen

    Daten in Zeilen und Spalten – mit Header-Zellen für beide Richtungen und einer Caption.

Navigation

  • Breadcrumbs

    Der Weg von der Startseite zur aktuellen Seite als geordnete Liste von Links.

  • Aktuelle Seite markieren

    Das Attribut aria-current kennzeichnet den Link, der auf die geöffnete Seite verweist.

Medien

  • Bilder

    Das Element img mit Alt-Text, Maßen und Caption.

  • Responsive Images

    Mehrere Dateien für ein Bild: Der Browser wählt nach der Breite des Viewports.

Formulare

  • Label und Fehlermeldung

    Jedes Feld hat ein Label. Der Browser prüft Pflichtfelder und markiert einen Fehler erst nach der Eingabe.

CSS-Architektur

  • Cascade Layers

    Ebenen ordnen die Regeln eines Style­sheets. Ihre Reihenfolge entscheidet vor der Spezifität.

  • Custom Properties

    Ein Wert unter einem Namen: an einer Stelle definiert, mit var() an vielen Stellen eingesetzt.

  • Progressive Enhancement

    Lesbar in jedem Browser; ein Ersatz mit @supports für Browser ohne ein Feature.

Layout

  • Flexbox

    Items in einer Richtung: mit Umbruch, verteiltem Platz und Gap.

  • Seitenlayout mit Grid

    Header, Hauptinhalt und Footer als benannte Grid Areas.

  • Spalten ohne Media Query

    Ein Grid, dessen Spaltenzahl dem Platz im Container folgt.

Responsive

  • Media Queries

    Regeln ab einem Breakpoint – Mobile-first beginnt mit der schmalen Form der Seite.

  • Größen mit clamp()

    Ein Wert zwischen Minimum und Maximum, der mit dem Viewport wächst – ohne Breakpoint.

  • Container Queries

    Regeln ab einer Breite des Query Containers: Eine Komponente folgt ihrem Platz, nicht dem Viewport.

Design-System

  • Design-Tokens

    Jeder Wert der Gestaltung unter einem Namen, der seine Aufgabe nennt.

  • Farben mit oklch()

    Helligkeit, Chroma und Farbton – und ein Kontrast von mindestens 4,5:1 für Text.

  • Dark Mode mit light-dark()

    Je Color Scheme eine Farbe in einer Deklaration – der Browser wählt.

Interaktion ohne JavaScript

  • Exklusives Akkordeon

    Mehrere details-Elemente mit demselben Namen: Es ist höchstens eines offen.

  • Popover-Menü

    Das Menü dieser Seite unter 64rem – ohne JavaScript.

Barrierefreiheit

  • Skip-Link

    Der erste Tab-Stopp jeder Seite führt direkt zum Hauptinhalt.

Custom Properties

Eine Custom Property speichert einen Wert unter einem Namen. Die Funktion var() setzt den Wert ein: Eine Änderung an einer Stelle wirkt an jeder Stelle, die den Namen verwendet.

Warum

Der Name einer Custom Property beginnt mit --. Die Toolbox definiert alle Custom Properties in tokens.css am Element :root. Jedes Element der Seite erbt die Werte.

Ohne Custom Properties steht derselbe Farbwert an jeder Stelle, die ihn verwendet. Eine andere Akzentfarbe verlangt dann eine Änderung an jeder dieser Stellen. Mit --accent-hue ändert sich eine Zeile: Die Datei overrides.css definiert den Farbton am Element :root neu.

Der Browser prüft den Wert erst beim Einsetzen. Ein ungültiger Wert macht die Deklaration ungültig, die ihn verwendet. Die Eigenschaft erhält dann den geerbten Wert oder ihren Anfangswert, nicht den Wert einer vorherigen Deklaration. Der Browser meldet keinen Fehler.

Der Browser berechnet eine Custom Property an dem Element, an dem sie definiert ist. --color-accent enthält an :root bereits den Farbton aus --accent-hue. Ein anderer Wert für --accent-hue an einem Element innerhalb der Seite ändert --color-accent deshalb nicht.

Barrierefreiheit

  • Die Farbe des Fokusrahmens ist eine Custom Property. Ein ungültiger Wert in --accent-hue entfernt den Fokusrahmen auf jeder Seite, ohne Meldung des Browsers.
  • Nach einer Änderung der Akzentfarbe ist der Kontrast von --color-accent-text zum Hintergrund zu prüfen: mindestens 4,5:1.

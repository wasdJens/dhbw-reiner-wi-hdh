Exklusives Akkordeon

Ein Element <details> zeigt seinen Inhalt erst nach einem Klick auf die Zeile <summary>. Mehrere Elemente mit demselben Wert im Attribut name bilden eine Gruppe: Der Browser hält höchstens eines davon offen.

Kategorie

Demo

Code

Warum

Ein Akkordeon zeigt von mehreren Einträgen nur den Titel. Der Inhalt erscheint auf Anfrage. Früher brauchte das JavaScript: ein Skript für das Öffnen und eines, das die übrigen Einträge schließt.

Das Element <details> übernimmt das Öffnen, das Attribut name das Schließen der übrigen Einträge. Enthalten zwei Einträge einer Gruppe schon im HTML das Attribut open, bleibt nur der erste offen.

Ein Akkordeon eignet sich für Inhalt, den nicht jede Person braucht. Inhalt, den jede Person lesen soll, steht offen auf der Seite.

Barrierefreiheit

  • Die Zeile <summary> hat im Accessibility Tree den Zustand expanded. Screenreader nennen, ob der Eintrag offen ist.
  • Jede Zeile <summary> ist ein Tab-Stopp. Enter und Leertaste öffnen und schließen den Eintrag.
  • Der Inhalt eines geschlossenen Eintrags fehlt im Accessibility Tree.

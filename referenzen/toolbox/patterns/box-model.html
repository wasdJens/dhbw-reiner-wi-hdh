Box Model

Jedes Element erzeugt eine Box aus Inhalt, padding, border und margin. box-sizing legt fest, ob width die Box bis zur border oder nur den Inhalt meint.

Kategorie
CSS-Grundlagen

Warum

Mit dem Anfangswert box-sizing: content-box gilt width nur für den Inhalt. padding und border kommen hinzu: width: 20rem mit padding: 2rem und einer border von 4 px ergibt eine Box von 392 px. Mit border-box ist die Box 320 px breit, und der Inhalt wird schmaler.

display legt fest, wie die Box im Textfluss steht. Eine Block-Box wie <p> beginnt in einer neuen Zeile und nimmt die ganze Breite ein. Eine Inline-Box wie <a> steht in der Zeile: width wirkt nicht, und padding oben und unten verschiebt die Zeilen nicht.

Treffen die Margins zweier Block-Boxen untereinander aufeinander, fallen sie zusammen. Der Abstand ist der größere der beiden Werte, nicht ihre Summe.

Logische Eigenschaften wie margin-block-start folgen der Schreibrichtung. In einem Text von oben nach unten legt margin-block-start den Abstand oben fest, padding-inline links und rechts.

Barrierefreiheit

  • Der Fokusrahmen ist eine outline. Sie gehört nicht zur Box und verschiebt beim Fokus kein Element.
  • padding gehört zur Box. Ein Klick auf das padding eines Links oder Buttons trifft das Element und vergrößert damit die Fläche zum Klicken (2.5.8 Target Size (Minimum)).

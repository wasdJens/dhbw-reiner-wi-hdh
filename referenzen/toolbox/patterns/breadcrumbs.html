Breadcrumbs

Breadcrumbs zeigen den Weg von der Startseite zur aktuellen Seite: eine geordnete Liste von Links in einer eigenen Navigation.

Kategorie
Navigation
Kapitel
Navigation & mehrere Seiten

Demo

Code

Warum

Die Main Navigation nennt die Ziele einer Website. Breadcrumbs nennen die Lage der aktuellen Seite: jede übergeordnete Seite von der Startseite bis zur Seite selbst. Die Reihenfolge der Links ist fest, deshalb ist die Liste ein <ol>. Jeder Link führt zu einer übergeordneten Seite.

Die Seite liegt im Ordner patterns. Die Pfade zur Startseite beginnen deshalb mit ../. Der mittlere Link verbindet einen Pfad mit einem Anchor: ../index.html#struktur.

Barrierefreiheit

  • Eine Seite mit Breadcrumbs enthält mindestens zwei Elemente <nav>. Das Attribut aria-label gibt jeder Navigation einen Namen. Ohne Namen sind die Navigationen im Accessibility Tree nicht unterscheidbar.
  • Der Name enthält das Wort „Navigation“ nicht. Screenreader sagen die Rolle navigation zusätzlich zum Namen an.
  • Der letzte Link trägt aria-current="page". Screenreader sagen ihn als aktuelle Seite an.
  • Die Trennzeichen zwischen den Links erzeugt das Style­sheet. Sie stehen nicht im HTML und gehören nicht zum Inhalt der Liste.

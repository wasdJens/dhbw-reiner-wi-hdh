Skip-Link

Ein Link am Anfang der Seite führt direkt zum Hauptinhalt. Er ist der erste Tab-Stopp und erscheint erst, wenn er den Fokus hat.

Kategorie
Barrierefreiheit
Kapitel
Barrierefreiheit prüfen

Demo

Code

Warum

Header und Sidebar stehen auf jeder Seite vor dem Hauptinhalt. Wer mit der Tastatur arbeitet, drückt ohne Skip-Link für jeden dieser Links einmal Tab, bevor der Fokus den Hauptinhalt erreicht. Ein Screenreader liest die Links in derselben Reihenfolge.

Das Erfolgskriterium 2.4.1 Bypass Blocks der WCAG 2.2 (Stufe A) verlangt einen Weg, wiederholte Blöcke zu überspringen. Landmarks erfüllen das Kriterium für Screenreader. Ein Skip-Link erfüllt es auch für Personen, die nur die Tastatur verwenden.

translate: 0 -200% schiebt den Link über den oberen Rand des Viewports. Der Link bleibt im Accessibility Tree und ist ein Tab-Stopp. Mit display: none wäre er beides nicht: Ein Element ohne Darstellung erhält keinen Fokus.

Barrierefreiheit

  • Der Skip-Link ist das erste Element von <body> und damit der erste Tab-Stopp.
  • Nach Enter steht der Fokus auf <body>, weil <main> keinen Fokus erhalten kann. Das nächste Tab führt zum ersten Link im Hauptinhalt.
  • Der Link hat sichtbaren Text. Screenreader lesen ihn wie jeden anderen Link vor.

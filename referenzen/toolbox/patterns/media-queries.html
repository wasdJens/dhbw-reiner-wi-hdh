Media Queries

Eine Media Query wendet Regeln ab einer Breite des Viewports an. Diese Breite ist der Breakpoint. Mobile-first beginnt mit der schmalen Form der Seite und ergänzt ab dem Breakpoint.

Warum

Die Regeln ohne Bedingung beschreiben die Seite für einen schmalen Viewport: eine Spalte, keine Sidebar. Der Block @media (width >= 64rem) ergänzt ab dem Breakpoint die zweite Spalte und stellt die Sidebar dar. Diese Reihenfolge heißt Mobile-first.

Eine Media Query erhöht die Spezifität einer Regel nicht. Bei gleicher Spezifität gewinnt die spätere Regel. Der Block steht deshalb nach den Regeln ohne Bedingung.

Die Einheit rem rechnet in einer Media Query mit der Schriftgröße, die im Browser eingestellt ist. Mit dem Standard von 16 px entspricht 64rem einer Breite von 1024 px. Eine Deklaration font-size am Element <html> verschiebt den Breakpoint nicht.

Die Bedingung einer Media Query liest keine Custom Property. var() wirkt nur in einer Deklaration. Der Wert des Breakpoints steht deshalb im Block selbst.

Barrierefreiheit

  • Ein Element mit display: none fehlt auch im Accessibility Tree und in der Reihenfolge von Tab. Inhalte, die unter einem Breakpoint fehlen, bleiben auf einem anderen Weg erreichbar.
  • Ein Breakpoint in rem folgt der Schriftgröße, die eine Person im Browser einstellt. Bei 20 px liegt der Breakpoint 64rem bei 1280 px.

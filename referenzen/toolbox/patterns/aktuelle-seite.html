Aktuelle Seite markieren

Das Attribut aria-current="page" kennzeichnet in einer Navigation den Link, der auf die geöffnete Seite verweist.

Kategorie
Navigation
Kapitel
Navigation & mehrere Seiten

Demo

Code

Warum

Eine Navigation nennt die Ziele einer Website. Die Markierung nennt zusätzlich den Ort, an dem sich die Person befindet. Eine Klasse wie class="active" erzeugt nur die sichtbare Markierung. Das Attribut aria-current="page" trägt dieselbe Information als Bedeutung im HTML.

Das Style­sheet wählt das Attribut aus: a[aria-current="page"]. Bedeutung und Gestaltung haben damit eine gemeinsame Quelle. Fehlt das Attribut, fehlt auch die sichtbare Markierung.

Barrierefreiheit

  • Screenreader sagen einen Link mit aria-current="page" als aktuelle Seite an.
  • Je Navigation trägt höchstens ein Link das Attribut. Der Validator prüft nur den Wert, nicht die Aussage: Eine Markierung am falschen Link meldet er nicht.
  • Die sichtbare Markierung verwendet nicht nur Farbe. Die Toolbox setzt den Link fett und stellt ein Quadrat davor.
  • Der markierte Link bleibt ein Link und ist mit Tab erreichbar.

Selektoren

Ein Selektor wählt die Elemente aus, für die eine Regel gilt. Er wählt nach Element, Klasse, ID, Attribut, Zustand und Lage im Dokument aus.

Kategorie
CSS-Grundlagen
Kapitel
CSS-Grundlagen

Demo

Code

Warum

Eine Regel enthält keine Liste von Elementen. Der Browser prüft für jedes Element im DOM, ob der Selektor zutrifft. Ein neues Element mit passender Lage, Klasse oder passendem Attribut erhält die Gestaltung ohne Änderung am Stylesheet.

Selektoren lassen sich kombinieren. Das Leerzeichen wählt Nachfahren aus, > nur direkte Kinder, + das direkt folgende Element. Eine Liste mit Komma wendet dieselbe Regel auf mehrere Selektoren an.

Ein Selektor, der auf kein Element zutrifft, erzeugt keine Fehlermeldung. nav > a wählt in der Toolbox kein Element aus, weil jeder Link der Navigation in einem <li> steht.

Barrierefreiheit

  • Der Selektor [aria-current="page"] gestaltet die aktuelle Seite über das Attribut, das ein Screenreader vorliest. Darstellung und Ansage hängen am selben Attribut und weichen nicht voneinander ab.
  • :focus-visible trifft auf das Element zu, das den Fokus hat, wenn der Browser einen sichtbaren Fokus anzeigt, zum Beispiel nach der Taste Tab.

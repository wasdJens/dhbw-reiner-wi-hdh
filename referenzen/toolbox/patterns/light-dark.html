Dark Mode mit light-dark()

Die Funktion light-dark() enthält je Color Scheme eine Farbe. Der Browser wählt nach der Einstellung des Betriebssystems.

Kategorie
Design-System
Kapitel
Design-System

Demo

Code

Warum

Die Deklaration color-scheme: light dark nennt die Color Schemes, die die Seite unterstützt. Der Browser wählt eines davon nach der Einstellung des Betriebssystems. light-dark() liefert im Light Mode die erste Farbe und im Dark Mode die zweite.

Ohne color-scheme liefert light-dark() immer die erste Farbe. Die Seite bleibt dann hell, auch wenn das Betriebssystem den Dark Mode verwendet.

Ältere Style­sheets definieren jede Farbe ein zweites Mal in einem Block @media (prefers-color-scheme: dark). Mit light-dark() stehen beide Werte in einer Deklaration.

Der Browser wertet light-dark() an dem Element aus, das die Farbe verwendet. Die Demo legt color-scheme an zwei Elementen fest. Die Textfarbe erbt ein Element als berechnete Farbe. Ein Bereich mit eigenem Color Scheme legt deshalb auch color fest.

Barrierefreiheit

  • Die Seite folgt der Einstellung der Person. Sie braucht kein Bedienelement und kein JavaScript.
  • Der Kontrast gilt je Color Scheme. --color-accent hat als Textfarbe im Dark Mode 7,25:1 und im Light Mode 3,11:1.
  • Bilder haben in beiden Color Schemes dieselbe Datei.

Landmarks

Header, Navigation, Hauptinhalt und Footer teilen eine Seite in Bereiche, zu denen Screenreader direkt springen können.

Kategorie
Struktur
Kapitel
Das Skelett

Demo

Code

Warum

Sehende erfassen den Aufbau einer Seite mit einem Blick. Screenreader brauchen dafür Landmarks: Sie listen die Bereiche auf und springen auf Tastendruck zum Hauptinhalt, statt die Navigation jedes Mal von vorn vorzulesen.

Barrierefreiheit

  • Genau ein <main> pro Seite.
  • <header> und <footer> werden nur als direkte Kinder von <body> zu banner und contentinfo.
  • Gibt es mehrere <nav>, bekommt jede einen Namen über aria-label.

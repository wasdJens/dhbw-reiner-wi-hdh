Tabellen

Das Element <table> ordnet Daten in Zeilen und Spalten. Header-Zellen benennen jede Spalte und jede Zeile, die Caption benennt die Tabelle.

Kategorie

Tabellen & Formulare

Demo

Code

Warum

Eine Tabelle ist die passende Struktur, wenn jede Zeile dieselben Angaben enthält. Die Demo nennt je Landmark zwei Angaben: die Rolle und den Inhalt. Eine Description List benennt die Angaben zu einem Begriff nicht.

<th> kennzeichnet eine Header-Zelle, <td> eine Datenzelle. Das Attribut scope nennt die Richtung einer Header-Zelle: col für die Spalte, row für die Zeile. <thead> enthält die Zeile mit den Header-Zellen der Spalten, <tbody> die Zeilen mit den Daten.

Eine Tabelle ordnet Daten, nicht die Seite. Die Anordnung von Bereichen einer Seite ist Aufgabe von CSS.

Barrierefreiheit

  • <caption> ist der Name der Tabelle im Accessibility Tree. Screenreader sagen ihn an, wenn die Person die Tabelle erreicht.
  • Header-Zellen haben die Rolle columnheader oder rowheader, Datenzellen die Rolle cell.
  • Screenreader sagen zu einer Datenzelle die zugehörigen Header-Zellen an. Der Wert ist dann ohne die übrige Tabelle verständlich.
  • In einer Tabelle ohne <th> hat jede Zelle die Rolle cell. Der Bezug zwischen Wert, Spalte und Zeile fehlt.

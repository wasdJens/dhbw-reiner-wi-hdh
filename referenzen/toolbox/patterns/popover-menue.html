Popover-Menü

Unter 64rem öffnet der Button „Menü“ die Navigation dieser Seite als Popover. Der Browser übernimmt das Öffnen, das Schließen mit Escape oder mit einem Klick neben das Menü und die Reihenfolge des Fokus. Die Seite enthält kein JavaScript.

Warum

Das Attribut popover macht ein Element zum Popover. Der Browser stellt es nicht dar, bis ein Button mit popovertarget es öffnet. Das offene Popover liegt über allen anderen Elementen der Seite. Escape und ein Klick daneben schließen es.

Der Browser gibt jedem Popover Standardwerte, zum Beispiel position: fixed und einen Rahmen. Ab 64rem überschreibt der Block @media diese Werte: Die Navigation steht dann als Sidebar in ihrer Spalte des Grids.

:has() trifft ein Element, wenn ein Nachfahre dem Selektor in den Klammern entspricht. html:has(.site-nav:popover-open) trifft das Element <html>, solange das Menü offen ist. Die Seite dahinter scrollt dann nicht.

Beim Öffnen wechselt display von none auf block. Ein Element ohne Darstellung hat keinen Wert, von dem eine Transition ausgeht. @starting-style legt diesen Startwert fest. allow-discrete verzögert beim Schließen den Wechsel von display und overlay bis zum Ende der Transition.

Barrierefreiheit

  • Der Button hat im Accessibility Tree den Zustand expanded. Screenreader nennen, ob das Menü offen ist.
  • Nach dem Öffnen führt Tab vom Button in das Menü. Escape schließt es und setzt den Fokus zurück auf den Button.
  • Ein geschlossenes Menü fehlt im Accessibility Tree und in der Reihenfolge von Tab.
  • Hat die Person im System Bewegung reduziert, erscheint das Menü ohne Bewegung.

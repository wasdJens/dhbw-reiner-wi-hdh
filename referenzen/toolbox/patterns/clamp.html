Größen mit clamp()

Die Funktion clamp() hält einen Wert zwischen einem Minimum und einem Maximum. Die Größe wächst mit dem Viewport, ohne Breakpoint.

Kategorie
Responsive
Kapitel
Responsive

Demo

Code

Warum

clamp() nennt drei Angaben: Minimum, Wert und Maximum. Der Wert 1.4rem + 2.6vw enthält die Einheit vw: 1vw ist ein Prozent der Breite des Viewports. Liegt der Wert unter dem Minimum, gilt das Minimum. Liegt er über dem Maximum, gilt das Maximum.

Schriftgröße der Hauptüberschrift bei 16 px je rem
Breite des Viewports Wert Schriftgröße
320 px 30,72 px 32 px (Minimum)
768 px 42,37 px 42,37 px
1280 px 55,68 px 52 px (Maximum)

Eine Media Query ändert einen Wert in Stufen. clamp() ändert ihn mit jedem Pixel der Breite. Die Toolbox verwendet clamp() für Größen und eine Media Query für den Wechsel des Layouts.

Ist das Minimum größer als das Maximum, gilt bei jeder Breite das Minimum.

Barrierefreiheit

  • Der Wert der Schriftgröße enthält einen Anteil in rem. Die Überschrift folgt deshalb der Schriftgröße, die eine Person im Browser einstellt.
  • Eine Schriftgröße nur in vw folgt dieser Einstellung nicht.

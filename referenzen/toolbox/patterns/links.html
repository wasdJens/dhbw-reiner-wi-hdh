Links

Ein Link verweist auf eine Datei im Projekt, auf eine andere Website oder auf eine Stelle der Seite. Der Linktext nennt das Ziel.

Kategorie
Text
Kapitel
Text & Semantik

Demo

Code

Warum

Das Attribut href bestimmt das Ziel. Ein Wert ohne Schema ist ein relativer Pfad: git-scm.com sucht eine Datei dieses Namens im Ordner der Seite. Erst https:// kennzeichnet die Adresse einer anderen Website. Ein Wert mit # führt zu dem Element mit der genannten id.

Barrierefreiheit

  • Screenreader listen alle Links einer Seite ohne den umgebenden Text auf. Der Linktext ist deshalb allein verständlich.
  • Linktexte wie „hier“ oder „mehr“ nennen kein Ziel. Mehrere Links mit demselben Text sind in der Liste nicht unterscheidbar.
  • Der Name eines Links im Accessibility Tree ist sein Linktext.
  • Links sind mit Tab erreichbar und mit Enter auslösbar. Der Fokus bleibt sichtbar.

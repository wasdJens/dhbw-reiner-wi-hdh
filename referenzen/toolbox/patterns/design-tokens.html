Design-Tokens

Ein Token ist eine Custom Property für einen Wert der Gestaltung. Sein Name nennt die Aufgabe, nicht das Aussehen. Jede Regel der Toolbox verwendet Tokens statt fester Werte.

Warum

Ein Token trennt eine Entscheidung von ihrer Verwendung. Die Entscheidung „Fließtext hat die Zeilenhöhe 1,6“ steht einmal in tokens.css. Jede Regel, die sie braucht, verwendet var(--leading-body).

Der Name nennt die Aufgabe. --color-paper ist im Light Mode hell und im Dark Mode dunkel. Ein Name nach dem Aussehen, zum Beispiel --color-white, wäre im Dark Mode falsch.

Ein fester Wert in einer Regel ist eine Entscheidung ohne Namen. Steht derselbe Wert an mehreren Stellen, zeigt das Style­sheet nicht, ob die Stellen zusammengehören. Die Toolbox enthält deshalb außerhalb von tokens.css keinen Farbwert und keinen Schriftnamen.

Die Schriftgrößen folgen einem Verhältnis von 1,25: 0.8rem, 1rem, 1.25rem, 1.5625rem. Die Abstände folgen einem Raster von 4 px.

Barrierefreiheit

  • Die Zeilenhöhe ist eine Zahl ohne Einheit. Jedes Element berechnet sie aus seiner eigenen Schriftgröße. Eine Zeilenhöhe mit Einheit erbt jedes Element als feste Länge.
  • Schriftgrößen und Abstände stehen in rem. Sie folgen der Schriftgröße, die eine Person im Browser einstellt.

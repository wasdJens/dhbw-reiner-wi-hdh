Spalten ohne Media Query

Ein Grid mit repeat(auto-fill, minmax()) erzeugt so viele Spalten, wie in den Container passen. Die Spaltenzahl folgt dem Platz, ohne Media Query.

Kategorie
Layout
Kapitel
Layout

Demo

Code

Warum

minmax(16rem, 1fr) legt die Breite einer Spalte fest: mindestens 16rem, darüber ein gleicher Anteil am freien Platz. repeat(auto-fill, …) wiederholt diese Spalte so oft, wie sie in den Container passt. In der Übersicht der Toolbox entstehen zwei Spalten, bei einem Viewport von 320 px eine.

auto-fill behält leere Spalten. Ein einzelner Eintrag ist so breit wie eine Spalte, und die Spalten aller Listen der Seite stimmen überein. auto-fit setzt leere Spalten auf die Breite 0: Ein einzelner Eintrag füllt dann den Container.

Flexbox mit flex-wrap verteilt den Platz je Zeile. Der letzte Eintrag einer Liste mit ungerader Anzahl füllt die ganze Zeile. Ein Grid hat gemeinsame Spalten für alle Zeilen.

Ist der Container schmaler als 16rem, ragt die Spalte über ihn hinaus. Die Toolbox wendet die Regel deshalb erst ab 16rem Breite des Query Containers an (siehe Container Queries). Ohne Container Query begrenzt minmax(min(100%, 16rem), 1fr) das Minimum auf die Breite des Containers.

Barrierefreiheit

  • Das Grid ändert die Rollen nicht. Der Accessibility Tree enthält weiter eine Liste mit ihren Einträgen.
  • Tab folgt dem Quelltext. In der Darstellung ist das die Reihenfolge zeilenweise von links nach rechts.

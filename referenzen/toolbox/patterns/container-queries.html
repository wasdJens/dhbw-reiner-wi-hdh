Container Queries

Eine Container Query wendet Regeln ab einer Breite des Query Containers an, nicht des Viewports. Eine Komponente folgt so dem Platz an ihrem Ort.

Kategorie
Responsive
Kapitel
Responsive

Demo

Code

Warum

Die Deklaration container-type: inline-size legt ein Element als Query Container fest. Die Regeln im Block @container (width >= 16rem) gelten für Elemente, deren nächster Query Container mindestens 16rem breit ist.

Die Pattern-Liste steht bei derselben Breite des Viewports in zwei Containern: in einer Sidebar mit 16rem und im Hauptinhalt. Eine Media Query unterscheidet die zwei Orte nicht. Mit der Container Query ist die Liste im schmalen Container eine Spalte ohne Linien und im breiten Container ein Grid mit Hairlines.

Die schmale Form steht in den Regeln ohne Bedingung, die breite im Block @container. Das entspricht Mobile-first, übertragen auf den Container.

Der Browser berechnet die Breite eines Query Containers ohne dessen Inhalt. Ein Element, dessen Breite sonst vom Inhalt abhängt, ist als Query Container 0 px breit. Ein Element fragt außerdem nie sich selbst ab: Die Regeln gelten für seine Nachfahren.

Barrierefreiheit

  • Die Container Query ändert nur die Darstellung. Beide Formen der Liste haben im Accessibility Tree die Rolle list.
  • Tab folgt in beiden Formen dem Quelltext.

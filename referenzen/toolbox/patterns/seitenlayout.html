Seitenlayout mit Grid

Das Seitenlayout ist ein Grid mit einer Spalte, drei Zeilen und drei benannten Grid Areas: Header, Hauptinhalt und Footer.

Kategorie
Layout
Kapitel
Layout

Demo

Code

Warum

grid-template-areas beschreibt das Grid mit Namen: je Zeichenkette eine Zeile, je Name ein Grid Area. grid-area ordnet ein Element einem Grid Area zu. Eine Änderung der Anordnung betrifft dann nur die Regel für body.

Die Zeilen haben die Höhen auto 1fr auto. Header und Footer sind so hoch wie ihr Inhalt, die mittlere Zeile erhält den freien Platz. Mit min-block-size: 100dvh ist das Grid mindestens so hoch wie der Viewport. Der Footer steht deshalb auch auf einer kurzen Seite am unteren Rand.

Die Spalte hat die Breite minmax(0, 1fr). Der Wert 1fr allein entspricht minmax(auto, 1fr): Die Spalte ist dann mindestens so breit wie der breiteste Inhalt ohne Umbruch, zum Beispiel eine lange Zeile in einem Code-Block. Mit dem Minimum 0 bleibt die Spalte so breit wie der Viewport, und die lange Zeile scrollt im Code-Block.

Ein Name in grid-area, den kein Grid Area trägt, erzeugt keine Meldung. Der Browser legt für das Element eine zusätzliche Spalte und eine zusätzliche Zeile an.

Ab einer Breite von 64rem ergänzt die Toolbox ein viertes Grid Area für die Sidebar.

Barrierefreiheit

  • Ein Grid Area legt den Ort eines Elements unabhängig von der Reihenfolge im Quelltext fest. Tab und Screenreader folgen dem Quelltext. Header, Hauptinhalt und Footer stehen dort in der Reihenfolge, in der die Seite sie zeigt.
  • Das Grid ändert die Landmarks nicht. Der Accessibility Tree enthält weiter banner, main und contentinfo.
